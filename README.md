# Tulpar

**Лёгкий редактор кода с ИИ везде — без телеметрии, на русском, казахском и английском.**

Движок как у VS Code (Monaco), но весит в разы меньше, ничего не отправляет «домой» и умеет то, чего в VS Code нет без десятка расширений: ИИ-агент, совместная правка по Wi-Fi, HTTP-клиент, машина времени для файлов, учебный режим и многое другое.

[⬇ Скачать для Windows](https://github.com/sasiskax27/Tulpar/releases/latest) · [Что нового](CHANGELOG.md) · [Архитектура](ARCHITECTURE.md)

> *A lightweight, telemetry-free code editor with AI everywhere. UI in English, Russian and Kazakh (Settings → Appearance → Language).*

## Все возможности

- Редактор на Monaco (движок VS Code): подсветка ~80 языков, мультикурсор, мини-карта, поиск и замена (`Ctrl+F` / `Ctrl+H`)
- Открытие папки, дерево файлов, автообновление при изменениях на диске
- **Проводник:** создать файл или папку (можно сразу с путём: `src/utils/x.ts`), переименовать (`F2`), удалить в корзину (`Delete`), контекстное меню, управление стрелками, подсветка открытого файла
- **Git** (`Ctrl+Shift+G`): изменённые файлы, разница «коммит ↔ сейчас» бок о бок, подготовка и откат, коммит (`Ctrl+Enter`), сообщение коммита от ИИ, ветки, push / pull, цветные метки изменённых строк на полях
- **Сборка и запуск:** Tulpar сам находит в проекте Maven, Gradle, npm / pnpm / yarn / bun, Cargo, Go, Python (pip, Poetry, uv), Make, CMake, .NET, Docker, Bundler, Composer, Dart / Flutter, Mix и предлагает их задачи — собрать, тесты, запустить (`Ctrl+Shift+B`). Кнопка ▶ (`Ctrl+F5`) запускает текущий файл: Python, JavaScript, TypeScript, Go, Rust, C, C++, Java, Kotlin, C#, PHP, Ruby, Lua, Perl, R, Julia, Dart, Swift, Scala, Bash, PowerShell и другие. Всё выполняется во встроенном терминале
- **Перетаскивание:** файлы и папки тянутся мышью на другую папку, файлы из проводника системы бросаются прямо в дерево (в том числе с другого диска) — в конце меню «Переместить / Копировать»
- **Поиск по проекту** (`Ctrl+Shift+F`): учёт регистра, слово целиком, регулярные выражения, фильтр файлов, замена во всех файлах (открытые меняются в редакторе с отменой через `Ctrl+Z`)
- Вкладки, сохранение, метка «не сохранено», восстановление сессии
- Палитра команд `Ctrl+Shift+P` и переход к файлу `Ctrl+P` (с учётом `.gitignore`)
- `settings.json`, `keybindings.json`, `layout.json` в формате VS Code — применяются на лету
- **Языковые серверы (LSP):** автодополнение с автоимпортом, ошибки, подсказки при наведении, подсказки параметров, переход к определению (`F12`), поиск использований (`Shift+F12`), переименование (`F2`), форматирование (`Shift+Alt+F`)
- **Встроенный терминал** (`Ctrl+\``): несколько вкладок, PowerShell на Windows и ваша оболочка на macOS и Linux, копирование и вставка, история сохраняется при скрытии панели
- **Окно настроек** (`Ctrl+,`): шрифт, отступы, тема, терминал, ИИ — без правки файлов; всё применяется сразу
- **ИИ-агент в чате** (кнопка «🤖 Агент»): дайте задачу словами — «добавь проверку ввода», «почини тесты», «создай README» — и агент сам найдёт нужные файлы, поправит код, запустит сборку или тесты и исправит ошибки. Каждый шаг виден в чате, а правки — прямо в редакторе, как у Copilot: файл открывается сам, новые строки подсвечены зелёным, удалённые помечены красным, сверху панель «Принять / Отклонить / Сравнить». Кнопка «⚡ Авто» — агент делает всё сам без вопросов (опасные команды вроде удаления папок или git reset --hard всё равно спросит), правки остаются подсвечены, их можно оставить или отменить. Нужна модель, умеющая вызывать инструменты: Claude, GPT, облачные модели Ollama и OpenCode Zen, а из локальных — qwen3.5:4b и больше, qwen2.5-coder:7b, llama3.1
- **GitHub Copilot:** подсказки при наборе через официальный Copilot Language Server, в том числе с бесплатным тарифом Copilot Free (Настройки → ИИ → «Войти в Copilot»)
- **Git и GitHub:** вход в GitHub, имя и почта для коммитов, клонирование и публикация проекта прямо из панели Git
- **Фон-видео и «стекло»:** картинка или видео на фоне, полупрозрачные панели с размытием
- **Слабый компьютер — не проблема:** облачные модели Ollama (`:cloud`, бесплатно с лимитом — Настройки → Локальный ИИ → «Войти» и «Установить»), OpenRouter (есть бесплатные модели) или платные OpenCode Zen, OpenAI, Claude. У каждого варианта ИИ свой список моделей — кнопка «Выбрать модель…»
- **Чат внизу, рядом с терминалом** (или в боковой панели — кнопка в заголовке чата): перетащите в чат файл или папку из проводника — они приложатся к вопросу; перетащите имя проекта — ИИ прочитает весь проект. То же — «Приложить к чату с ИИ» по правому клику
- **Тема из фоновой картинки**: поставьте фото фоном — интерфейс, код и терминал перекрасятся в его цвета (Настройки → Внешний вид → Тема → «Из фоновой картинки» или кнопка «Тема по картинке»)
- **Проблемы** (`Ctrl+Shift+M`, внизу рядом с терминалом и в строке статуса): все ошибки и предупреждения проекта списком, клик — к месту в коде; «✦ Исправить с ИИ» для одной ошибки, файла или всех сразу, а также в лампочке прямо в редакторе. Сюда же попадают ошибки из терминала: упавшая программа на Python (Traceback), ошибки сборки Rust/Cargo, gcc/clang, Go, javac/Maven, Kotlin/Gradle, TypeScript, C#, Node.js
- **Раздел «Сборка»**: Tulpar находит Maven, Gradle, npm, Cargo, Go, Python, Make, CMake, .NET и другие сборщики и показывает их задачи — запуск одной кнопкой, кнопка «Стоп», запуск текущего файла
- **Два дизайна** (Настройки → Внешний вид → Стиль интерфейса): Дизайн 1 — полоса иконок и панели-острова; Дизайн 2 — верхняя панель с ИИ-островом и боковая панель, которая выезжает при наведении на левый край. Темы «Ночная степь», «Беркут», «Рассвет» (плюс классические тёмная и светлая), полоса иконок слева/справа/скрыта, вид вкладок, скругление, промежутки, шрифт интерфейса
- **Фоновая картинка:** перетащите PNG или JPG в окно; яркость, размытие и размер настраиваются
- **ИИ по правому клику:** выделите код → «ИИ: Добавить комментарии», «Исправить ошибки», «Упростить», «Объяснить», «Свой запрос» (`Ctrl+I`). Работает с локальной Ollama, любым OpenAI-совместимым сервером или Claude
- **Чат с ИИ** (`Ctrl+Alt+I`): ответы потоком, ИИ видит открытый файл или выделение, приложенные файлы и список файлов проекта, а с кнопкой «Весь проект» — код всего проекта (если не помещается, Tulpar выбирает самые подходящие к вопросу файлы); блоки кода с кнопками «Копировать» и «Вставить», ссылки `файл:строка` открывают нужное место; работает с Ollama, OpenAI-совместимыми серверами и Claude
- **Свои действия ИИ:** в настройках задаёте название и инструкцию — появляется пункт «ИИ: …» в меню по правому клику и в палитре
- **Восстановление после сбоя:** несохранённые правки сохраняются в резервную копию; если Tulpar закрылся (вылет, выключили свет), при следующем открытии папки он предложит их вернуть
- **Языковые серверы одной кнопкой:** если сервер не найден, в уведомлении кнопка «Установить» — команда запускается во встроенном терминале
- **Русский, английский и казахский интерфейс:** Настройки → Внешний вид → «Язык интерфейса» (или первый шаг мастера). По умолчанию — как в системе; ИИ отвечает на языке интерфейса
- **Расширения из Open VSX** (`Ctrl+Shift+X`): темы VS Code (Dracula, One Dark, Material, Catppuccin…) и наборы сниппетов ставятся одной кнопкой. Код расширений не запускается — только темы и сниппеты, поэтому Tulpar остаётся лёгким
- **Библиотеки для всех языков:** раздел «Библиотеки» ищет по npm, PyPI, crates.io, Maven Central, NuGet, Go, pub.dev, Packagist и RubyGems. Tulpar сам понимает, чем собирается проект (npm/pnpm/yarn/bun, pip/uv/Poetry, Cargo, Maven, Gradle, Go, .NET, Flutter, Composer, Bundler), показывает подключённые библиотеки и добавляет новые одной кнопкой: командой в терминале, а в Maven и Gradle — прямо в pom.xml / build.gradle
- **@-упоминания в чате:** `@main.py @терминал почему падает?` — ИИ получает файл, вывод терминала, `@ошибки`, `@git` (diff) или `@выделение`
- **Проверка перед коммитом:** кнопка «🔍 Проверить» в Git ищет ключи и пароли в коде, забытые `console.log`/`breakpoint()`, маркеры конфликтов, а с ИИ — ещё и баги
- **Панель «Тесты»:** pytest, Vitest, Jest, cargo test, go test, Maven, Gradle, .NET — запуск, дерево результатов, перезапуск одного теста, «✦ Исправить с ИИ»
- **Блокноты Jupyter (.ipynb):** ячейки, графики matplotlib, таблицы pandas, `input()`. Jupyter ставить не нужно — свой лёгкий ядро-процесс Python
- **Базы данных:** файлы SQLite открываются кликом; раздел «Базы данных» подключается к PostgreSQL (Supabase, Neon), MySQL/MariaDB и MongoDB (Atlas) — дерево таблиц, SQL-запросы, фильтры документов, защита от случайных DELETE/DROP
- **Живой предпросмотр сайта:** `npm run dev` → Tulpar сам замечает `localhost:5173` и предлагает открыть сайт справа
- **🌐 HTTP-клиент** (как Postman, без аккаунта): методы, заголовки, тело, переменные `{{base}}`, история; вставьте `curl …` — превратится в запрос; «Копировать как curl / fetch / Python»; ИИ составит запрос по описанию и объяснит ошибку сервера
- **🔣 Лаборатория регулярок:** подсветка совпадений, группы, замена, объяснение по кусочкам, готовые шаблоны (email, телефон KZ/RU, ИИН…), ИИ делает регулярку по описанию
- **📋 Доска TODO:** все `TODO`, `FIXME`, `HACK`, `NOTE` из комментариев проекта — карточками по колонкам, клик ведёт к строке
- **⏳ Машина времени:** каждое сохранение файла и каждая правка ИИ-агента сохраняются локально — ползунок по версиям, сравнение и восстановление даже без git
- **📊 Моя статистика:** сколько минут вы реально пишете код, языки, серия дней подряд, самое продуктивное время и фокус-таймер «помидор». Только на вашем компьютере
- **🧰 Инструменты:** JSON → TypeScript, красивый/сжатый JSON, Base64, URL, разбор JWT, SHA-хэши, UUID, Unix-время, camelCase/snake_case, цвета и контраст — всё локально, без сомнительных сайтов
- **👥 Вместе по сети:** несколько Tulpar в одной Wi-Fi правят одни файлы одновременно — с цветными курсорами и именами, как в Google Docs. Без серверов в интернете: хозяин показывает ссылку или QR, гость вставляет её и подключается
- **🔍 ИИ-ревью всего проекта:** ИИ читает весь код частями и находит баги, дыры в безопасности, медленные места и забытые ключи; оценка проекта из 100, клик — к строке, «✦ Исправить» отдаёт задачу агенту
- **🔐 .env без утечек:** секреты в редакторе размыты, пока курсор не на их строке; таблица переменных, предупреждение, если .env не в .gitignore, и `.env.example` одной кнопкой
- **🪄 Генератор файлов:** .gitignore, Dockerfile, .dockerignore, docker-compose, GitHub Actions CI, .editorconfig, README и лицензия MIT — под стек проекта, а ИИ может подогнать их под ваш код
- **Просмотр PDF, SVG и картинок:** PDF открывается прямо в редакторе, SVG — кодом с живым предпросмотром рядом, у картинок масштаб (Ctrl+колесо), размер и шахматный фон
- **🎤 Режим презентации** (`Ctrl+Alt+P`): крупный шрифт, только код, нажатые сочетания клавиш на экране, всё вне выделения приглушается — для уроков, стримов и роликов. Выход — `Shift+Esc`
- **📑 CSV таблицей:** сортировка по клику, фильтр, сумма/среднее по столбцу, правка ячеек прямо в таблице
- **💡 Ошибки простыми словами:** наведите на подчёркнутое — объяснение по-человечески для частых ошибок и кнопка «✦ Объяснить с ИИ»
- **Синхронизация настроек через GitHub** (секретный gist) и **галерея тем**: своя тема из палитры, «поделиться» кодом или файлом
- **Подсказки ИИ при наборе:** серый текст продолжения, `Tab` — принять. С Ollama модель видит код и до, и после курсора, поэтому даже маленькая `qwen2.5-coder:1.5b` подсказывает быстро и к месту. Включается в настройках, раздел «ИИ»

## Языки

**Подсветка** — около 80 языков сразу (движок Monaco).

**Умные функции** (автодополнение, ошибки, определение, переименование):
- встроены: JavaScript, TypeScript, JSON, HTML, CSS, SCSS, Less;
- настроены — нужен языковой сервер, Tulpar предложит установить его кнопкой:

| Язык | Сервер | Установка |
|---|---|---|
| Rust | rust-analyzer | `rustup component add rust-analyzer` |
| Python | basedpyright | `pip install basedpyright` |
| Go | gopls | `go install golang.org/x/tools/gopls@latest` |
| C / C++ / Objective-C | clangd | `winget install LLVM.LLVM` / `brew install llvm` / `apt install clangd` |
| Java | jdtls | `scoop install jdtls` / `brew install jdtls` |
| C# | csharp-ls | `dotnet tool install --global csharp-ls` |
| PHP | intelephense | `npm install -g intelephense` |
| Lua | lua-language-server | `winget install LuaLS.lua-language-server` / `brew install lua-language-server` |
| Kotlin | kotlin-language-server | `scoop install kotlin-language-server` / `brew install kotlin-language-server` |
| Ruby | ruby-lsp | `gem install ruby-lsp` |
| Scala | metals | `cs install metals` |
| Dart | входит в Dart SDK | — |
| Swift | sourcekit-lsp, входит в Swift | — |
| R | languageserver | `Rscript -e "install.packages('languageserver')"` |
| Bash | bash-language-server | `npm install -g bash-language-server` |
| YAML | yaml-language-server | `npm install -g yaml-language-server` |
| Dockerfile | docker-langserver | `npm install -g dockerfile-language-server-nodejs` |

Сервер запускается, только когда открыт файл его языка.

Любой другой язык — одна строка в `languages.json` (палитра → «Настройки: Открыть languages.json»):

```jsonc
{
  "zig": { "command": "zls" },
  "typescript": { "command": "typescript-language-server", "args": ["--stdio"] }
}
```

## ИИ

Откройте настройки (`Ctrl+,`), раздел «ИИ», и выберите один из вариантов:

- **Ollama** — бесплатно, модель работает на вашем компьютере, код никуда не уходит. В разделе «Локальный ИИ» — каталог из 25 моделей: Tulpar показывает, какие запустятся на вашем железе, скачивает выбранную с прогрессом и сам подключает её.
- **OpenAI-совместимый** — OpenAI, OpenRouter, LM Studio и другие: адрес сервера, модель и ключ.
- **Claude** — ключ API из консоли Anthropic; модель по умолчанию `claude-sonnet-5-5`.

Tulpar отправляет код только по вашей команде и только на указанный сервер. Ключ хранится открытым текстом в `settings.json` — не выкладывайте этот файл.

## Настройки

Файлы лежат в папке настроек (`~/.config/tulpar` на Linux, `~/Library/Application Support/tulpar` на macOS, `%APPDATA%\tulpar` на Windows). Открыть их можно из палитры команд: «Настройки: Открыть settings.json» и т.д.
