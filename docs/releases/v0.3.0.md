# Tulpar 0.3.0 🐎

Самое большое обновление: казахский язык, совместная работа по Wi-Fi, ИИ, который знает ваш проект, игры и десятки инструментов, которых нет в VS Code из коробки.

## 🇰🇿 Қазақша
Интерфейс на казахском языке, и ИИ отвечает по-казахски. Настройки → Основное → Язык.

## 🧠 ИИ стал умнее
- **Project Brain** — Tulpar запоминает ваш проект (стек, команды, правила) и учитывает это в каждом ответе.
- **Команда ИИ** — кодер → тестировщик → ревьюер решают задачу по очереди.
- **ИИ-ревью всего проекта** — баги, безопасность, забытые ключи, оценка из 100.
- **Ошибки простыми словами** — наведите на подчёркнутое.
- **Код голосом** — `Ctrl+Alt+V`.
- Исправлено: маленькие модели больше не оставляют ```` ``` ```` в файлах.

## 👥 Вместе по сети
Несколько человек в одной Wi-Fi правят одни файлы одновременно, с курсорами — без серверов в интернете.

## 🩺 Проверки и безопасность
- **Tulpar Doctor** — проверяет Git, Node/Python/Rust, зависимости, .env и чинит одной кнопкой.
- **Центр безопасности** — уязвимые пакеты по базе OSV.dev, ключи в коде, защита .env.
- **.env без утечек** — секреты размыты в редакторе.

## 🛠 Инструменты
HTTP-клиент · лаборатория регулярок · доска TODO · машина времени для файлов · лента событий и поиск по истории · Docker · CSV таблицей · просмотр PDF и SVG · генератор .gitignore / Dockerfile / CI · JSON → TypeScript, JWT, Base64, хэши, цвета.

## 🎮 Игры и фан
Битва с ИИ · Найди баг · скоростная печать кода · викторина · змейка · 30 ачивок · Power mode · музыка (Spotify, YouTube, свои mp3) · красивые скриншоты кода · режим презентации · таймлапс в видео.

## ⚙ Удобство
- Настройки разложены по 6 понятным группам.
- Режим для слабых ПК одной кнопкой.
- Переносная версия: положите рядом с `tulpar.exe` пустой файл `portable` — все данные будут храниться рядом с программой.
- Быстрее запуск: инструменты загружаются только когда нужны.

## Установка
Скачайте `Tulpar_0.3.0_x64-setup.exe` ниже. Если Windows покажет «Windows защитила ваш компьютер» — нажмите **Подробнее → Выполнить в любом случае** (у программы пока нет цифровой подписи).
