## Как проверить терминал
1. `` Ctrl+` `` → внизу открывается PowerShell в папке проекта.
2. Наберите `dir` или `git status` → вывод с цветами, кириллица читается.
3. Потяните границу панели → текст перестраивается под новую ширину.
4. `` Ctrl+Shift+` `` → второй терминал во вкладке «2».
5. `` Ctrl+` `` дважды → панель скрылась и вернулась, история на месте.
6. Наберите `exit` → вкладка терминала закрывается.

Другая оболочка — в `settings.json`:
```jsonc
{ "terminal.integrated.shell": "cmd.exe" }
```
