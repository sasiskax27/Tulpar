## Ваши задачи

Хорошие модули, чтобы освоиться в проекте. Каждая задача — отдельный коммит.

### Проводник — `src/explorer/Explorer.tsx`
1. **Подсветка активного файла.** Строка файла из активной вкладки (`activePath()` из `editor/tabs.ts`) выделяется фоном `--tp-bg-selected`.
2. **Иконки по типу файла.** Начните с простого: цветная буква или эмодзи по расширению (`.ts`, `.rs`, `.py`, `.go`, `.json`, `.md`). Позже заменим на темы иконок VS Code.
3. **Кнопка «Свернуть всё»** в заголовке панели.
4. **Навигация с клавиатуры:** стрелки вверх/вниз, Enter — открыть, ← / → — свернуть/раскрыть.
5. **Контекстное меню:** новый файл, новая папка, переименовать, удалить. Для этого понадобятся новые команды в ядре (`src-tauri/src/workspace/mod.rs`) — тут я помогу.

### Строка статуса — `src/app/StatusBar.tsx`
1. **Счётчик несохранённых файлов** (`tabs.filter(t => t.dirty).length`).
2. **Клик по раскладке** → команда `tulpar.layout.next`.
3. **Клик по «Стр, стлб»** → переход к строке (нужна новая команда `workbench.action.gotoLine`, Monaco умеет это сам: `editor.getAction("editor.action.gotoLine")`).

## Как проверить

```bash
npm install
npm run tauri dev
```

1. `Ctrl+K Ctrl+O` → открыть папку проекта Tulpar.
2. `Ctrl+P` → набрать `tabs` → Enter: открывается `src/editor/tabs.ts`.
3. Изменить текст → на вкладке точка. `Ctrl+S` → точка исчезла.
4. `Ctrl+,` → в `settings.json` добавить `"workbench.colorTheme": "light"` и сохранить → тема меняется сразу.
5. Закрыть и снова открыть Tulpar → папка и вкладки на месте.
