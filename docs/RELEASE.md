# Как выпустить новую версию

Tulpar сам проверяет GitHub Releases (раз в 12 часов) и предлагает обновиться.
Чтобы это сработало, релиз нужно оформить так:

1. **Поднять версию** в трёх местах (одинаково, например `0.2.0`):
   - `package.json` → `"version"`
   - `src-tauri/tauri.conf.json` → `"version"`
   - `src-tauri/Cargo.toml` → `version`
2. **Собрать:**
   ```
   npm run tauri build
   ```
   Готовые файлы:
   - `src-tauri\target\release\bundle\nsis\Tulpar_0.2.0_x64-setup.exe` — установщик (нужен для автообновления);
   - `src-tauri\target\release\tulpar.exe` — сама программа (можно положить в zip для тех, кто не хочет устанавливать).
3. **GitHub → Releases → Draft a new release:**
   - Tag: `v0.2.0` (буква v и та же версия);
   - перетащить `Tulpar_0.2.0_x64-setup.exe` (обязательно, имя должно оканчиваться на `-setup.exe`) и, если хочется, zip;
   - в описании — что нового и подсказка: «Windows может показать “Система Windows защитила ваш компьютер” → Подробнее → Выполнить в любом случае».
   - Publish release.

У пользователей старой версии появится «Вышла новая версия Tulpar 0.2.0» → «Обновить»:
Tulpar скачает установщик, запустит его и закроется.

Черновики и pre-release не предлагаются — только опубликованный последний релиз.
