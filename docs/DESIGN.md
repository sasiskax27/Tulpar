# Дизайн Tulpar

Tulpar будет поддерживать два стиля интерфейса. Выбор — в настройках:
**Внешний вид → Стиль интерфейса**, ключ `workbench.style` в `settings.json`.

| | Дизайн 1 — «Классический» | Дизайн 2 — «Tulpar» |
|---|---|---|
| Ключ | `"classic"` (по умолчанию) | `"tulpar"` |
| Для кого | Привыкшим к VS Code | Тем, кто хочет красивый и спокойный редактор |
| Состояние | Работает сейчас | Макет готов, перенос — позже |

Макеты: холст «Tulpar — стиль окна» (claude.ai artifact). Главный макет — **«Итог · Tulpar»**, он интерактивный (кнопка Play).

## Дизайн 1 — «Классический»

То, что есть сейчас: полоса иконок слева, проводник, вкладки, строка статуса, раскладка из `layout.json`. Похоже на VS Code — людям легко перейти.

## Дизайн 2 — «Tulpar»

Идея: на экране только код, всё остальное появляется, когда нужно.

### Окно
- **Без постоянных панелей.** Сверху: логотип, вкладки открытых файлов, ИИ-остров, шестерёнка, кнопки окна.
- **Боковая панель выезжает**, когда мышь у левого края, и прячется, когда мышь уходит. Код при этом плавно раздвигается и сужается (≈380 мс). Настройка «Прятать боковую панель» отключает автоскрытие.
- В панели: **проекты** (переключение одним кликом, «Открыть папку…»), **файлы**, внизу **Настройки** (`Ctrl+,`).
- Все панели — **острова**: скруглённые (16–24 px), с тенью, на 10 px от краёв.
- При «уменьшить движение» в системе анимации отключаются.

### ИИ-остров
Как Dynamic Island: одна капсула по центру сверху, три состояния:
1. **Покой** — строка «Файл, команда или вопрос ИИ» и метка модели («ИИ · 7B»).
2. **Работает** — золотая рамка, индикатор, «ИИ исправляет fastest… 3 с», кнопка «Отмена».
3. **Ответ** — капсула раскрывается в карточку: объяснение, мини-diff «было/стало», «Отменить» / «Принять (Tab)».

### Код
- Без рамки, прямо на фоне, во всю высоту. Справа **мини-карта** с метками правок и ошибок.
- Путь над кодом: `tulpar › examples › herd.py › fastest`; закреплённый заголовок текущей функции.
- **Вид кода** (настройка):
  - **Чистый** — код и мини-карта;
  - **Умный** — плюс строка над функциями «3 использования · Объяснить · Написать тест», стрелки сворачивания, автор текущей строки, подсвеченная линия отступа текущей функции;
  - **Фокус** — как «Умный», а код вне текущей функции притушен (прозрачность 0.38).
- Детали: курсив для комментариев, параметров и декораторов; ключевые слова чуть жирнее; подсказки типов в строке (`herd: list[Rider]`); ошибка — волнистое подчёркивание и текст в конце строки; текущая строка — мягкий фон цвета акцента; цветная полоска на полях у новых (зелёная), изменённых (акцент) строк и ошибок (красная).
- Шрифт по умолчанию — JetBrains Mono 14 px, высота строки ×1.65. На выбор: Fira Code, IBM Plex Mono. Интерфейс — Onest. Все шрифты с кириллицей.

### Тема из фото
Пользователь перетаскивает фото — Tulpar строит тему вокруг его главного цвета:
1. Фото уменьшается до 48×48. Точки раскладываются по 24 корзинам оттенка; вес точки = насыщенность × близость яркости к 55%. Серое, чёрное и белое почти не считаются.
2. Оттенок самой тяжёлой корзины — основа темы, её средняя насыщенность (35–85%) — насыщенность акцента.
3. Тема строится в HSL от этого оттенка с фиксированными яркостями (фон 7%, острова 11%, текст 89%, акцент 66%…), поэтому читаемость не зависит от фото. Цвета подсветки — оттенок, повёрнутый на постоянные углы (+60° ключевые слова, +150° строки, −40° числа…).
4. Само фото — за кодом, прозрачность 0.2, размытие 3 px.

Реализация — в макете `Final.dc.html`, методы `paletteFrom` и `themeFromHue`.

## План переноса
1. Темы кода в Monaco: три темы + `themeFromHue` для фото.
2. Настройка `workbench.style` и раскладка «Tulpar»: выезжающая панель, острова.
3. ИИ-остров вместо всплывающего индикатора ИИ.
4. Вид кода: мини-карта (есть в Monaco), CodeLens над функциями (есть в LSP), режим фокуса.
5. Тема из фото поверх уже работающей фоновой картинки.
