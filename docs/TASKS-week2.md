## Как проверить
1. Установите сервер своего языка (таблица в README).
2. Откройте папку с проектом на этом языке и любой файл.
3. Сделайте ошибку → через секунду подчёркивание.
4. Наберите имя переменной или `.` после объекта → список автодополнения.
5. `F12` на имени функции → переход к определению.
6. Если сервер не найден, Tulpar покажет уведомление с командой установки.
