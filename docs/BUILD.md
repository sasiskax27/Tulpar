# Сборщик Tulpar

## В редакторе

- **▶** в верхней панели (или на левой панели) — собрать и запустить выбранное.
- **Ctrl+Shift+B** — собрать, **F6** — собрать и запустить, панель «Сборка» внизу — выбрать цель.
- Tulpar сам находит проекты в открытой папке и её подпапках: Android (Gradle), Flutter, Node (скрипты package.json), Rust, Go, Python, .NET, CMake, Gradle, Maven, make.
- Чего не хватает — ставит сам: Java, Android SDK, Gradle, Node.js, Python, Go (портативно, в папку Tulpar).
- Для Android один раз спросит согласие с лицензией Android SDK от Google — это ваше решение, Tulpar сам его не принимает.
- Ошибки в выводе кликабельны, попадают в «Проблемы», кнопка «✦ Объяснить» и «Исправить с ИИ».

## Полная версия установщика

Обычный установщик весит ~15 МБ. Полная версия везёт внутри Java 21 (Eclipse Temurin) и Gradle 8.14.3:

```
npm run build:full
```

Скрипт `scripts/fetch-toolchain.mjs` скачивает их в `src-tauri/toolchain`, а `src-tauri/tauri.full.conf.json`
кладёт папку в установщик. При первом запуске Tulpar распаковывает их в свою папку языков.

Android SDK в установщик не кладётся: лицензионное соглашение Android SDK не разрешает его распространять.
Он скачивается с серверов Google при первой Android-сборке, после согласия человека с лицензией.
