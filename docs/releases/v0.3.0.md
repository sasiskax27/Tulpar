# 🐎 Tulpar 0.3.0 — «Дала»

> Редактор кода, который сделал студент из Шымкента.
> Лёгкий. Без слежки. С ИИ в каждом углу. И теперь — на қазақша.

Это не обновление. Это **другой редактор**. За одну версию Tulpar научился тому, на что VS Code нужен десяток расширений, — и остался таким же быстрым.

---

## 🇰🇿 Сәлем, Қазақстан!
Первый редактор кода с интерфейсом **на казахском языке**. ИИ отвечает по-казахски и пишет комментарии в коде на родном языке.
`Настройки → Основное → Язык → Қазақша`

## 🧠 ИИ, который знает твой проект
- **Project Brain** — Tulpar один раз изучает проект и запоминает всё: стек, папки, команды, твои правила. ИИ больше не задаёт глупых вопросов.
- **Команда ИИ** — три агента по очереди: 👨‍💻 кодер пишет → 🧪 тестировщик проверяет → 🔍 ревьюер находит баги. Ты просто пьёшь чай.
- **ИИ-ревью всего проекта** — баги, дыры в безопасности, забытые пароли. Оценка из 100 и «✦ Исправить» одной кнопкой.
- **Ошибки простыми словами** — наведи на красное подчёркивание, и Tulpar объяснит по-человечески.
- **Код голосом** — `Ctrl+Alt+V`, говоришь «сделай кнопку» — получаешь кнопку.

## 👥 Кодим вместе. Без интернета.
Два ноутбука, одна Wi-Fi — и вы правите один файл одновременно, с цветными курсорами и именами, как в Google Docs. Никаких серверов, аккаунтов и подписок. Ссылка или QR — и вы в деле.

## 🩺 Одна кнопка — и проект работает
**Tulpar Doctor** проверяет всё: Git, Node, Python, Rust, зависимости, `.env`, устаревшие пакеты. Нашёл проблему — жмёшь «Исправить всё». Больше никаких «а у меня не запускается».

## 🛡 Безопасность, как у больших
- Проверка пакетов по мировой базе уязвимостей **OSV.dev** — с кнопкой «Обновить».
- Поиск забытых ключей и паролей в коде.
- Секреты в `.env` **размыты прямо в редакторе** — можно спокойно снимать стрим.

## 🎮 Кодить — это весело
- ⚔️ **Битва с ИИ** — одна задача, кто решит быстрее: ты или машина?
- 🐞 **Найди баг** · ⌨️ **Скоростная печать кода** · 🧠 **Викторина** · 🐍 **Змейка**, пока идёт сборка
- 🏆 **30 ачивок** с конфетти — «Ночной кодер», «Пальцы-молнии», «Охотник на баги»…
- ⚡ **Power mode** — искры из-под курсора и счётчик КОМБО
- 🎧 **Музыка прямо в редакторе** — Spotify, YouTube, Яндекс Музыка или свои mp3

## 🎬 Для тех, кто снимает
- 🎤 **Режим презентации** (`Ctrl+Alt+P`) — крупный код и нажатые клавиши на экране
- 📸 **Красивые скриншоты кода** (`Ctrl+Alt+C`) — градиент, тень, «made in Tulpar»
- ⏪ **Таймлапс** — как рос твой файл, в одном видео

## 🧰 И ещё целый ящик инструментов
HTTP-клиент как Postman · лаборатория регулярок · доска TODO · ⏳ машина времени для файлов · 🎞 лента событий и поиск «где мы это чинили?» · 🐳 Docker · CSV таблицей · PDF и SVG · генератор `.gitignore` / Dockerfile / CI · JSON → TypeScript, JWT, Base64, хэши, цвета

## 🪶 Лёгкий, как и обещали
- Инструменты загружаются **только когда нужны** — запуск быстрее.
- **Режим для слабых ПК** — одной кнопкой.
- **Версия на флешке** — положи рядом с `tulpar.exe` пустой файл `portable`, и Tulpar живёт где угодно.
- Настройки разложены по 6 понятным группам.
- Ноль телеметрии. Как и всегда.

## ⬇ Установка
1. Скачай **`Tulpar_0.3.0_x64-setup.exe`** ниже.
2. Если Windows покажет «Windows защитила ваш компьютер» — нажми **Подробнее → Выполнить в любом случае**. Это потому, что у молодого проекта пока нет платной цифровой подписи. Код открыт — можешь проверить сам.
